Wavelength Mentorship Platform

A web platform for Wavelength, a mentorship community for the software industry, where members earn credits by mentoring junior developers and spend them on sessions. Planned, built and presented to the client over a few weeks by a small student team.

  • Python
  • Flask
  • SQL
  • HTML & CSS
  • JavaScript
View code on GitHub

My role & team

This was my first team project at university, built with Akshay Karsan, Thomas Brown and Harley Doe. It's where I learned to use Git with other people, to split work across a shared codebase, and how the client-server model fits together on a real Flask back end.

Key features

  • Registration and login, with verification codes sent by email.
  • Mentor and mentee profiles, tags and communities.
  • A credit system: generating, tracking, donating and removing credits, with a leaderboard.
  • User file uploads.
  • Structured code: Flask blueprints for each area of the site, repository classes for data access, and a separate logic layer.

Security

  • Hashed passwords using passlib's salted, multi-round sha256_crypt.
  • Parameterised SQL in every repository class to prevent injection.
  • Session-based access control on protected routes, plus a site-permissions table for role-based features.
  • Email verification codes as an extra check on accounts.

What I'd improve next

  • Generate password salts with Python's secrets module; the random module isn't cryptographically secure.
  • Move password hashing to a memory-hard algorithm such as Argon2.
