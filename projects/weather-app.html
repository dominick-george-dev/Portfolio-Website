Weather App

A small JavaScript app I built to strengthen my front-end skills: search for a city and it shows the current temperature, humidity and wind speed from the OpenWeather API.

  • JavaScript
  • HTML
  • CSS
  • REST API
View code on GitHub

5 screenshots: use the arrows or scroll sideways.

How it works

An async fetch requests the city's weather from the OpenWeather API, shows an error message for unknown cities, then updates the page and swaps the weather icon to match the conditions (clouds, clear, rain, drizzle, mist or snow).
