Merchant Ship Game

A turn-based terminal game from my first year: steer your merchant ship (M) around a sea of pirates (P) and rocks (*) and trick the pirates into crashing.

  • Python
View code on GitHub

How it plays

You pick a difficulty, then move one square at a time (N/E/S/W). End up next to a pirate or a rock and your ship is lost; the aim is to lure the pirates into the rocks instead. It was my first game, and the main challenge was moving pieces around a 2D array without breaking the rules.
