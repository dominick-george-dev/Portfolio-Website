This Portfolio Website

The site you're reading: hand-written HTML, CSS and JavaScript with no frameworks, hosted on GitHub Pages at domgeorge.dev.

Design

A dark theme with a crimson accent, a background grid that lights up under the cursor, and a 3D rotating menu on the home page that you can spin with the scroll wheel, a swipe or the arrow keys. Every page is responsive down to small phones.

Security

Every page ships a strict Content Security Policy: scripts, styles, fonts, images and frames can only load from this site (plus Google Fonts for the typeface), with no inline scripts and no third-party JavaScript or tracking. There's also a security.txt file so issues can be reported responsibly.

Performance & accessibility

Images are resized WebP files with explicit dimensions and lazy loading, which cut image weight from about 8.5 MB to 1 MB. The markup is semantic, with a skip link, visible focus styles, keyboard support for the 3D menu and image carousels, alt text on every image and reduced-motion support. Links and HTML are checked automatically by GitHub Actions on every push.
