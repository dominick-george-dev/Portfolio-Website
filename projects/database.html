Database Design

A first-year assessment to design and implement a database to industry standards, modelling a co-working space with memberships, desk and meeting-room bookings, payments and reports.

Approach

Before writing any SQL I planned the system with use-case context diagrams and sliced the work into small stories using SPIDR. Getting the planning right first made the implementation far easier, a lesson I've carried into every project since.
